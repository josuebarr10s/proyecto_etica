# 🧭 Conectando Caminos: Alfabetización Digital Inclusiva para Migrantes

> Plataforma web comunitaria y educativa de alfabetización digital y ciberseguridad orientada a personas migrantes, familias en tránsito y comunidades de retorno en Guatemala. Desarrollada bajo la metodología de **Aprendizaje-Servicio** en colaboración con la **Escuela Normal Rural de Occidente (ENRO)** y la **Universidad Rafael Landívar (URL)**.

---

## 🌟 Características Principales

1. **Diagnóstico y Rutas de Aprendizaje Personalizadas:**
   - Selector interactivo por perfil (Recién llegado, En tránsito, Familia/Estudiante, Retornado).
   - Módulos organizados por habilidades esenciales (Conectividad segura, Trámites y Remesas, Búsqueda de Empleo, Prevención de Estafas).

2. **Herramientas Prácticas e Interactivas:**
   - **Simulador de Phishing y Ciberseguridad:** Reconocimiento práctico de SMS, mensajes falsos de WhatsApp y ofertas de empleo fraudulentas frente a canales oficiales.
   - **Creador de Currículum Digital Móvil:** Asistente paso a paso para estructurar un CV profesional y descargarlo directamente en el teléfono.
   - **Pre-Test y Post-Test Pedagógico:** Evaluación diagnóstica y final interactiva con cálculo de mejora de aprendizaje y generación de certificado digital de finalización.

3. **Muro Comunitario de Experiencias:**
   - Publicación de testimonios y consejos con **filtro ético en tiempo real** para prevenir la divulgación accidental de datos sensibles (DPI, números de tarjeta o teléfono).
   - Moderación comunitaria ética y opción de publicación anónima.

4. **Directorio de Emergencias y Casas del Migrante:**
   - Líneas directas gratuitas (IGM 1572, PNC 110, Bomberos Voluntarios 122).
   - Ubicación y contacto de albergues y Casas del Migrante en Ciudad de Guatemala, Tecún Umán, Esquipulas y Quetzaltenango.

5. **Accesibilidad e Inclusión:**
   - Paleta de colores cálida y ergonómica diseñada para uso prolongado en dispositivos móviles.
   - Barra de accesibilidad con escalado tipográfico dinámico (A, A+, A++) y modo de alto contraste.
   - Botón de Alerta / SOS siempre visible.

## ⚖️ Marco Ético (ACM 2018)

El diseño y desarrollo de la plataforma se rigen por los principios del Código de Ética de la **Association for Computing Machinery (ACM 2018)**:
- **Principio 1.1:** Contribuir a la sociedad y al bienestar humano, reconociendo a todas las personas como partes interesadas.
- **Principio 1.2:** Evitar el daño, mitigando riesgos de estafas, robo de identidad y desinformación.
- **Principio 1.4:** Ser justo y tomar medidas para no discriminar (accesibilidad universal y gratuidad total).
- **Principio 1.6:** Respetar la privacidad y proteger la confidencialidad (cero rastreo intrusivo, moderación de datos sensibles).

## 🛠️ Tecnologías Utilizadas

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Librería UI:** React 19 & TypeScript
- **Estilos:** Tailwind CSS con tokens y temas cálidos personalizados
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Efectos:** Canvas Confetti

## 🚀 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/josuebarr10s/proyecto_etica.git

# 2. Ingresar al directorio
cd proyecto_etica

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación en funcionamiento.
